## 4. 更新手順

1. 決定者が選択肢と理由を本書へ記録する。
2. 状態を `決定済み` にし、決定日を追記する。
3. 影響する要件、設計、DB、タスク、テストを同じ変更で更新する。
4. 実装後に決定を変える場合は、データ移行・互換性・ロールバックも記録する。
